# Pipecat + the services this agent uses. Verified against pipecat-ai 1.3.0.
# NOTE vs example 03: there is NO speech-to-text here — the AutonomousUserDriver
# synthesizes the user side — so the `deepgram` extra is intentionally omitted.
#   runner    -> the dev runner + prebuilt browser UI (http://localhost:7860/client)
#   webrtc    -> local WebRTC call in the browser (the default, no account needed)
#   daily     -> optional: join a Daily room instead (`-t daily`, needs an account)
#   google    -> the LLM (Gemini)
#   elevenlabs-> text-to-speech
pipecat-ai[runner,webrtc,daily,google,elevenlabs]~=1.3.0

# That's it — no STT, no extra logging or dotenv dependency. ojin.load_env() reads
